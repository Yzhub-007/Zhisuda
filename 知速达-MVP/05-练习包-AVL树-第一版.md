## 二、分层练习

### 基础(概念识记)

**1.** 讲义中空树的高度被定义为多少?
A. 0  B. -1  C. 1  D. 未定义
- 答案:B
- 解析:空树为 -1,单个节点为 0。
- 知识点:K1
- 原文依据:§1.1 Definition 1.1, p.1-1, "The height of an empty tree is defined to be -1"
- 依据状态:已核对

**2.** AVL 树中任意节点的平衡因子 BF(x) 可能取哪些值?
A. 0, 1  B. -1, 0, 1  C. -2 到 2  D. 任意整数
- 答案:B
- 解析:AVL 要求左右子树高度差的绝对值不超过 1,所以 BF 只能是 -1、0、1。
- 知识点:K4
- 原文依据:§1.2 Definition 2.2, p.1-2, "BF (x) = hL - hR"
- 依据状态:已核对(讲义中"-1, 0, 1"取值句的符号在文本提取时有缺失,需对照 PDF 原件确认)

**3.** 一棵有 n 个节点的二叉搜索树,节点连成一条单链时,树的高度是多少?
A. log n  B. n/2  C. n-1  D. n
- 答案:C
- 解析:链上 n 个节点有 n-1 条边,高度按边数计为 n-1。
- 知识点:K1、K2
- 原文依据:§1.1, p.1-1, "to n - 1 (if the nodes form a single chain)"
- 依据状态:已核对

**4.** 关于单旋转,下列说法正确的是?
A. 旋转后可能破坏搜索树性质  B. 旋转保持搜索树性质,且只需常数次操作  C. 旋转需要遍历整棵子树  D. 旋转只能用于根节点
- 答案:B
- 解析:旋转只重新连接少数几个指针,所以是常数代价,且保持搜索树性质。
- 知识点:K5
- 原文依据:§1.2.1 Proposition 1.1, p.1-4, "A single rotation will preserve the search tree property."
- 依据状态:已核对

### 标准(理解应用)

**5.** 设 n_h 为高度 h 的 AVL 树的最少节点数,已知 n_0 = 1,n_1 = 2,递推式为 n_h = n_{h-1} + n_{h-2} + 1。求 n_3。
A. 5  B. 6  C. 7  D. 8
- 答案:C
- 解析:n_2 = n_1 + n_0 + 1 = 4,n_3 = n_2 + n_1 + 1 = 7。
- 知识点:K7
- 原文依据:§1.2.3 Proof 2.1, p.1-6, "n_h = n_{h-1} + n_{h-2} + 1"
- 依据状态:已核对

**6.** 在 AVL 树插入新节点后,从最近的失衡节点 x 出发,朝新节点方向向下走两步,先向左再向右。应采用哪种调整?
A. 一次单旋转  B. 一次双旋转  C. 不需要调整  D. 重建整棵树
- 答案:B
- 解析:两步方向相反属于 zig-zag,需要双旋转。方向相同才是 zig-zig,用单旋转。
- 知识点:K6
- 原文依据:§1.2.2, p.1-5, "it is a zig-zag, and a double rotation is called for"
- 依据状态:已核对

**7.** 向 AVL 树插入一个新节点后,哪些节点的高度可能发生变化?
A. 整棵树所有节点  B. 只有根到新节点路径上的节点  C. 只有新节点的兄弟  D. 只有叶子节点
- 答案:B
- 解析:插入只会改变根到新节点路径上节点的高度,其他节点子树未变。
- 知识点:K6
- 原文依据:§1.2.2 Proposition 1.2, p.1-5, "nodes on the path from the root to the newly inserted node only"
- 依据状态:已核对

### 拓展(综合分析,简答)

**8.** 简述:为什么 n 个节点的 AVL 树高度是 O(log n)?
- 参考答案:设 n_h 为高度 h 的 AVL 树的最少节点数,则 n_h = n_{h-1} + n_{h-2} + 1,解得 n_h = F_{h+3} - 1(F 为斐波那契数)。n_h 随 h 指数增长,所以 n 个节点的树高度 h = O(ln n)。
- 解析:关键是从"最少节点数"反推高度上界。
- 知识点:K7
- 原文依据:§1.2.3 Proof 2.1, p.1-6, "This implies that h = O(ln n)"
- 依据状态:已核对

**9.** 简述:在 zig-zig 情形下,为什么插入后只做一次单旋转,就能让受影响子树的高度恢复到插入前?
- 参考答案:设子树 Z 高度为 h,则 X、Y 的高度也是 h,插入前以 k2 为根的子树高度为 h+2。插入后 X 子树高度变为 h+1,k2 的高度变为 h+3,k2 失衡。右旋后以 k1 为根的子树高度为 h+2,与插入前相同,所以上层节点不再失衡。
- 知识点:K6
- 原文依据:§1.2.2 Case 1, p.1-6, "The height of the tree root at k1 is h + 2."
- 依据状态:已核对

**10.** 简述:插入和删除在重平衡时所需的旋转次数有何不同?原因是什么?
- 参考答案:插入后,一次单旋转或双旋转即可恢复平衡。删除后可能需要 O(ln n) 次旋转。原因:插入时旋转使受影响子树高度恢复到插入前,不会向上传导。删除时旋转后的子树高度可能降低,失衡会沿路径向上传导。
- 解析:结论部分讲义有明确表述。"为什么会向上传导"的原因讲义没有解释,是推理。
- 知识点:K8
- 原文依据:§1.2.4 Proof 2.2, p.1-7, "we might need O(ln n) rotations for the delete"
- 依据状态:需人工核验(原因部分为推理,需教师确认;讲义中该结论处的数学符号提取不完整)
