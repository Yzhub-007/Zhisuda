# 知速达:基于课程资料溯源的 AI 智能复习包生成工具

> 本稿按赛题"场景 / 用户 / 痛点 / 方案 / 效果验证"组织。标【待填】的地方必须用真实测试数据替换,不得估算或编造。

## 1. 场景

问题发生在**期末复习前的备课与练习环节**:教师要为基础不同的学生准备复习练习,学生做完后教师还要整理共性问题。

当前选定的演示课程:《高级数据结构与算法分析》,Lecture 1 AVL 树(课堂讲义,7 页)。

## 2. 用户

| 用户 | 使用时刻 | 要完成的事 |
|---|---|---|
| 教师 / 助教 | 考前一两周 | 把讲义变成分层练习,并确保题目和答案可靠 |
| 学生 | 考前复习 | 选适合自己的档位练习,对照原文纠错,把卡点反馈给老师 |

测试对象实际身份:【待填:教师/助教/学长等,如实写】

## 3. 痛点

- **出题耗时:** 同一内容要出基础、标准、拓展多档题。【待填:教师访谈中的耗时原话】
- **AI 出题不敢直接用:** 大模型可能编造事实,教师需要重新验证一遍,省不了多少时间。
- **反馈整理靠人工:** 学生的错误和卡点分散,难以快速归纳。【待填:访谈原话】

## 4. 方案

流程:教师上传讲义 → AI 提炼知识点并生成三档练习(每项附章节、页码和原文短句) → 教师逐题审核 → 学生分层练习 → AI 汇总共性问题。

三个设计点:
1. **资料溯源:** 每题带原文依据;找不到依据则标"需人工核验",不猜测、不编页码。
2. **教师审核闭环:** 通过 / 修改 / 退回,审核后才发给学生。
3. **分层练习:** 基础、标准、拓展三档。
