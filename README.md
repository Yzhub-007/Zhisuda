# 知速达 Zhisuda

基于课程资料溯源的 AI 智能复习包生成工具。

教师上传课程讲义,AI 生成分层练习,**每道题都附讲义原文依据**。教师逐题审核后发给学生,学生的作答和卡点再被整理成共性问题清单。

> 赛题方向:04 教育 · 作品形式:AI 应用。
> 当前是**人工辅助的 MVP**,用于验证思路,还不是成品。

## 解决什么问题

| | |
|---|---|
| 场景 | 期末复习前,教师为基础不同的学生准备练习并整理反馈 |
| 用户 | 教师 / 助教(审核、发布),学生(分层练习) |
| 痛点 | 出分层题耗时;直接用 AI 出题无法快速核验;反馈整理靠人工 |
| 方案 | 带原文依据的分层练习 + 教师审核 + 反馈汇总 |

## 核心设计

1. **资料溯源。** 每个知识点和每道题都带章节、页码和原文短句。找不到依据的内容标为"需人工核验",不猜测、不编页码。
2. **程序级核对。** 模型给出的原文引用,程序会检查它是否真的出现在讲义里。找不到的,即使模型声称"已核对",也会被降级。
3. **教师审核闭环。** 每题可标"通过 / 修改 / 退回",审核后才发给学生。
4. **分层练习。** 同一份讲义生成基础、标准、拓展三档题。

流程:

```text
教师上传讲义 → AI 提炼知识点 + 三档练习(附依据)
            → 教师审核(通过 / 修改 / 退回)
            → 学生按档位练习,提交作答与卡点
            → AI 汇总共性错误 + 讲解建议 → 教师
```

## 快速开始

需要 Node.js 22 及以上。

```bash
cd 知速达-App
cp .env.example .env     # 填写 LLM_API_KEY,或把 LLM_MOCK 设为 1 先看界面
npm start                # 打开 http://127.0.0.1:3000
npm test                 # 依据核对逻辑的单元测试
```

模型接口使用兼容 OpenAI `chat/completions` 的服务即可,如 DeepSeek、通义千问、Kimi。详见 `知速达-App/README.md`。

只想看界面,不需要 Node:直接双击 `知速达-MVP/demo.html` 和 `student.html`。

## 局限

- 只覆盖一门课的一讲(《高级数据结构与算法分析》Lecture 1 AVL 树)。
- 程序核对的是"引用是否存在于讲义",**不是**"引用能否支持答案"。后者必须教师判断,不能当作依据准确率。
- 讲义只支持粘贴文字,不解析 PDF。
- 没有登录、数据库、自动批改。审核结果刷新即丢失,需先导出 CSV。
- 服务只监听本机且无认证,**不要暴露到公网**。
- 学生页尚未接入后端服务,反馈数据需手工合并。

## 讲义授权

示例讲义是课堂笔记,首页声明课堂外分发需任课教师许可。因此**原件 PDF 不在本仓库中**(已在 `.gitignore` 排除)。使用或公开展示前,请先取得任课教师同意。
