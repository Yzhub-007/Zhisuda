# 知速达｜让课程笔记变成可追溯的复习练习

**把自己的课程资料变成可直接作答、每题都能回到原文核对的复习包。**

导入课程资料 → 选择题量与题型 → 生成复习包 → 作答并回看出处 → 整理薄弱点。

知速达面向学生自学，重点不是多生成几道题，而是让复习题能指回自己的课程资料，并把“开始练习”做得更直接。

## 能做什么

- 导入 DOCX、文字版 PDF，或粘贴课程文字；生成前可检查提取结果，也可选择章节或页面。
- 所选内容达到 1 万字符时，生成前先确认将发送和跳过的章节／页面；取消则不发送任何资料。
- 按需要选择题量、题型和难度；题目附有原文短句及其所在位置，方便回到资料核对。
- 生成失败或刷新页面不丢资料：导入内容暂存在当前浏览器（不含 API 密钥），可调整后手动重试，不会自动重复调用模型。
- 默认可直接开始练习；人工核对是可选项。选择题自动核对，简答题由学生对照要点自评。
- 暂存未完成练习，回看错题和薄弱点，并在需要时继续练习。
- 错题按固定的 1／3／7 天间隔安排复习并显示排期原因，首页提示今日到期题数；这是可解释的固定规则，不是自适应算法，效果尚未验证。

## 项目现状

这是面向浙客松 AI+X 破界黑客松天猫校园 OPC 赛道的学生复习原型。项目作者已用自己的课程笔记试过上传流程；这属于上传流程的初步试用，不构成真实模型出题质量或学习效果的验证。

**目前还没有公开在线体验网址。** 打开固定演示样例无需 API；使用自己的资料实时生成时，需要用户自行填写兼容的模型 API。详细体验步骤和资料去向见[学生体验指南](学生体验指南.md)。

## 我们刻意说明的边界

- 原文引用能帮助定位资料，不能单独证明答案正确或引用足以支持答案；重要题目仍应回看原文。
- 文字版 PDF 可提取文字，扫描版 PDF 需要先做 OCR；复杂表格、公式和分栏仍需检查。
- 课程文字会在用户点击生成后发送给用户选择的模型服务；记录保存在运行服务的电脑，未提交答案暂存在浏览器。不同浏览器通过随机 cookie 区分工作区，但没有账号、云同步、身份找回或完整的公网访问与资源控制。
- 选择题按参考答案核对；简答题采用学生自评，不提供自动评分。

## 后续方向

1. 用更多已授权课程资料和真实学生试用，评估题目可用性、引用质量及首次开始练习的时间。
2. 优先补齐公网身份隔离、持久化、请求与费用限制，再考虑公开部署。
3. 根据试用反馈评估扫描资料 OCR、复杂版式处理和复习安排；不会把尚未验证的学习效果当成产品结论。
