# 知速达 Zhisuda

基于课程资料溯源的 AI 智能复习包生成工具，主要服务希望用自己的课程笔记进行主动回忆练习的学生。

**导入课程资料 → 生成复习包 → 直接练习 → 随题回看原文 → 回顾薄弱点。**

知速达把学生手里的课程材料变成可作答、可查出处的复习题，减少在“整理资料”和“开始复习”之间的操作。人工核对是可选功能，不是开始练习的必经步骤。

目前是面向浙客松天猫校园 OPC 赛道的本地比赛原型，尚未上线；真实模型出题质量和实际学习效果仍待验证。

## 本次更新（2026-10-18）

- **学习与模拟测试**：学习模式先作答再逐题核对答案、解析与原文；模拟测试整组提交后统一反馈。核对后的原回答锁定，模式和反馈随暂存恢复。
- **错题筛选与历史回看**：按课程、知识点、最近 7／30 天筛选错题，整组重练遵循当前筛选；历史可回看指定场次，也可开始新一轮。

- **按章节或页面选范围**：导入 DOCX／PDF 后可勾选要复习的标题章节或页面，只有选中的内容发送给模型；原文位置标签保持不变。
- **生成前选题型与难度**：可只出选择题或简答题，也可限定基础、标准、拓展；服务端会过滤模型越界的题目。
- **练习页三项筛选**：难度、题型、知识点同时生效，按钮显示随其他条件变化的题量，并可一键清除。
- **整组错题重练与练习历史**：错题本可按复习包重练全部待巩固题；新增练习历史页，显示每次的题量、客观题得分和简答自评进度，不折算总分。

- **题量可选，数量说清楚**：支持选择 1—30 道题，分别显示请求数、模型返回数和实际可练数；默认展示整包题目，难度筛选会标明数量。
- **生成过程看得见**：点击后弹出生成进度和已用时间，收起后保留顶部状态；刷新接回同一任务，避免重复调用模型。
- **练习可以暂停和继续**：自动暂存未提交答案，支持保存并返回首页；提交后错题标红并有文字提示，错题本支持查看原文和单题重练。
- **API 可选加密记住**：Windows 本机可选择加密保存，刷新或重启后无需重填；也可仅本次使用，或主动忘记已保存配置。
- **记录保存与备份更清楚**：不同浏览器使用独立本机工作区；日常直接打开继续，换环境时可备份、合并恢复全部学习记录，不包含 API 密钥。
- **补充使用说明与验证**：更新启动、保存和恢复说明，新增竞品功能对照；37 项自动化测试通过，模型测试使用本机模拟服务。

## 当前功能

- **导入自己的资料**：上传 DOCX、文字版 PDF，或粘贴课程文字；提取后先预览，再决定是否生成。
- **按需要生成**：可选 1—30 道题，可限定题型、难度和复习范围（章节或页面），点击后立即弹出进度；收起后仍可查看任务状态，刷新接回同一任务。资料不足时如实减少，不复制题目凑数。
- **先回忆，再看答案**：默认完成整包题目，也可按难度、题型、知识点组合筛选；学习模式逐题核对，模拟测试整组提交后查看参考答案、解析与原文引用。选择题按参考答案核对，简答题对照要点自评。
- **随题回到课程原文**：引用定位到 Word 标题及非空段落，或 PDF 文件页序；可选核对页能高亮引用并编辑题目。
- **按需人工核对**：生成前可选择“先核对题目，再开始练习”，也可从已保存的草稿进入核对；需要时再通过、退回、修改题目。
- **继续练习与错题本**：作答即时暂存在当前浏览器，退出后可继续；客观错题和简答自评薄弱项进入错题本，可查看原文，单题或整组重练；练习历史按次回顾。
- **本地保存与隔离**：不同浏览器使用独立本机工作区；日常无需导入，关闭后用同一浏览器、同一地址继续。可一键备份全部学习记录，换环境后恢复；也支持旧 `workspace.json` 导入和仅题目 JSON 导出。

直接练习会标明未经人工核对的题目数量和自动排除数量，不会把“引用存在”标成“答案正确”。复习包是保存时的独立快照，后续编辑草稿不会改变已有包。

## 快速体验

需要 Node.js 22 或更高版本；不需要下载本地大模型。首次下载后，进入 `知速达-App` 文件夹执行：

```powershell
npm ci --ignore-scripts --omit=optional
npm start
```

在浏览器打开 [http://127.0.0.1:3000](http://127.0.0.1:3000)。Windows 也可在依赖安装后双击 `启动知速达.cmd`。保持启动窗口打开，结束时按 `Ctrl+C`。

点击“载入可演示样例”，即可直接练习自编的《记忆与学习策略》题目，无需密钥、不消耗模型额度。样例含 6 道预设题，其中 1 道引用故意不存在，直接练习时会排除，留下 5 道。固定样例有明确标识，不代表实时 AI 生成。

## 谁提供 API？

**谁生成，谁提供自己的 API；练习已经保存的复习包不需要 API。** 项目不预设由开发者为所有用户提供额度。

在导入页点击“设置自己的 API”，填写服务商给出的接口地址、模型名称和密钥。支持兼容 `/chat/completions` 的官方服务及中转站，外部地址需使用 HTTPS；模型须能按要求返回 JSON。尚未验证特定服务商的兼容性。

- “保存设置并使用”只保存／启用设置，不调用模型，不消耗模型额度。
- “测试连接并保存设置”发送一条不含课程资料的短指令，可能产生少量费用；连接成功不能保证出题正确。
- 上传预览在本机进行；点击生成后，预览文字及位置标签会发送给用户选择的模型服务，原文件不发送给模型。
- 在自己的 Windows 电脑上，可勾选“在这台电脑记住 API（加密保存）”，用当前 Windows 账户保护本机密钥文件；刷新、关闭或重启知速达后可继续使用。页面不会取回密钥明文，密钥不进入浏览器存储、课程记录、备份 JSON 或应用日志。同一 Windows 账户下的其他人仍可能使用该配置；公用电脑请勿勾选。其他系统暂不提供此加密保存方式。
- 不勾选时仅本次使用，刷新、关闭或跳转到练习页后清空。模型设置中可主动忘记已保存配置，不影响复习包。
- 使用中转站时，密钥和生成文字会经过该站点。费用由填写密钥的账号承担。

## 溯源能保证什么？

程序会核对引用短句是否存在于课程文字中，并用实际匹配到的段落或文件页序替换模型自报的位置。Word 不推测页码，PDF 文件页序不一定等于印刷页码。

引用存在不能证明答案受到充分支持，也不能纠正原笔记本身的错误。未经人工核对的题目会明确提示；有疑问时可回看原文或进入可选核对。自动检查不等于经过独立验证的事实核查。

当前的薄弱点提示来自作答和自评规则，尚未实现经过验证的自适应学习、长期记忆调度或简答题自动评分。

## 当前限制

- 仅监听本机 `127.0.0.1`，不同浏览器通过随机 cookie 使用独立目录，但没有账号、云同步或找回机制；这不等同于公网权限控制。线上版本还需完成登录授权、费用和资源限制及可靠持久化。
- 单文件最多 12 MB、PDF 最多 200 页；生成文字需 200—60000 字符，超限拒绝，不自动截断。扫描 PDF 需先做 OCR（文字识别）。
- Word 图形、公式、批注、页眉页脚不作为已识别内容；PDF 的分栏、表格和公式顺序需要检查。
- `知速达-App/data/workspaces/<随机标识>/workspace.json` 可能包含完整课程文字与练习记录；旧版本也可能存在 `data/workspace.json`。整个 `data` 目录已加入忽略规则，不应公开提交。复习包 JSON 导出含题目答案和短引用，不含完整课程材料及练习记录，也不能代替完整备份。
- “我的复习包”中可“备份全部学习记录”并恢复，包含课程文字、复习包、成绩和本浏览器暂存答案，不含 API 密钥。恢复合并已有记录，不覆盖同 ID 的服务端记录，暂存答案优先保留较新版本；清除浏览器数据前请先备份，密钥需重新填写。尚无账号同步、OCR 或自动安排复习日程。学生使用意愿、题目质量和复习价值仍需试用验证。
- 早期 AVL 材料涉及讲义授权限制，讲义原件不在仓库中；当前固定演示使用自编材料。

下一阶段优先用授权课程材料验证真实出题质量、首次开始练习所需时间，以及学生是否愿意再次使用，再决定扩展功能。
