# 知速达 App · 学生自助复习原型

上传课程资料 → 生成复习包 → 直接练习 → 查看原文依据 → 保存学习记录。人工核对可选。

本应用使用 Node.js 原生 HTTP 服务，DOCX／PDF 解析依赖 `fast-xml-parser`、`fflate`、`unpdf`，需要 Node.js 22+，无需前端编译或本地大模型。

本次更新包括学习／模拟测试、错题按课程／知识点／最近练习时间筛选、指定历史场次回看，以及按章节／页面选择复习范围、生成前限定题型与难度、练习页难度／题型／知识点组合筛选、整组错题重练与练习历史，以及此前的自选题量、弹出式生成进度、练习自动暂存与继续、错题本及单题重练、Windows 可选 API 加密保存，以及全部学习记录备份恢复。简要改动见[仓库首页](../README.md#本次更新2026-10-18)，使用步骤和保存规则见下文。

## 启动与测试

首次下载，在本目录执行：

```powershell
npm ci --ignore-scripts --omit=optional
npm start
```

打开 [http://127.0.0.1:3000](http://127.0.0.1:3000)。Windows 可双击 `启动知速达.cmd`；脚本只检查运行条件并启动，不自动安装软件或改系统配置。结束时在窗口按 `Ctrl+C`。

点击“载入可演示样例”即可免密钥体验。不要直接双击 HTML 文件，完整功能需要服务运行。

自动测试命令：

```powershell
npm test
```

37 项测试覆盖范围选择、题型难度限制、练习筛选、练习历史、文件解析、原文定位、API 适配及错误、临时密钥不持久化、Windows 账户加密与重启使用、密钥不回传、工作区隔离、自选题数、生成任务、幂等提交、错题状态、可选核对门槛、独立快照、作答自评、全量导出与合并恢复。测试使用独立临时目录和随机本机端口，不改默认数据；输出默认保留在仓库父级 `_verification`，可由 `ZHISUDA_TEST_ROOT` 指定。Windows 加密专用测试在其他系统跳过。

浏览器验证使用本机 Chrome 和外部开发工具，不属于应用运行依赖；模型路径使用模拟服务，尚未证明真实模型质量或学习提升。

## 两种开始方式

| 方式 | 操作与结果 |
|---|---|
| 直接开始练习（默认） | 生成后自动保存练习包并打开练习页；排除引用无法定位、字段不完整或已退回的题目。未经人工核对的题目数量会显示在练习页 |
| 先核对题目，再开始练习 | 生成后进入可选核对页，可修改、通过或退回题目。可随时点击“直接开始练习”，也可处理完全部题目后保存仅含已通过题目的包 |

人工通过要求：题目字段完整、引用存在，并由使用者确认引用能支持答案。编辑后保存会重置该题的人工结论；未保存的修改会阻止开始练习。直接练习不会替使用者勾选人工确认，也不会修改草稿的核对状态。

相同草稿、修订号和开始方式重复保存会返回同一个包；不同方式分别保存。包是独立快照，修改草稿不改变旧包。刷新恢复最近草稿，重启服务保留已保存数据；练习中的未提交答案即时暂存在当前浏览器，退出后可以继续。

练习默认展示整包题目，也可按难度、题型、知识点三项组合筛选（取交集）；各按钮显示应用其他条件后的题量，数量为 0 的选项置灰，切换筛选保留答案。选择题由服务端按参考答案核对，简答题由学生对照要点自评。客观错题和未掌握的简答进入错题本，可单题重练，也可按复习包重练全部待巩固题；“练习历史”页按次列出题量、客观题得分和简答自评进度，不把自评折算成分数；统计按练习次数，允许同一个人重复贡献，不代表学生人数。

## 学习与模拟测试

练习页默认学习模式，可在开始核对前切换为模拟测试。学习模式先独立作答，再逐题查看答案、解析和原文；核对后锁定原回答，简答可对照要点自评。逐题核对不增加历史场次，点击底部“完成本轮”后统一保存当前筛选的题目和自评。未完成状态暂存在当前浏览器，可通过全部学习记录备份迁移。

模拟测试完成当前筛选的全部题目并提交后统一反馈；旧版暂存按模拟测试恢复。两种模式均用于本机自学，不提供正式考试防作弊。

错题可按课程、知识点、近 7／30 天最近练习时间筛选，整组重练遵循当前筛选。历史显示模式并可回看指定场次或开始新一轮；新一轮清空该包原有未提交暂存，保留已提交历史。

新增交互尚未做真实浏览器和手机布局验证；自动化测试验证接口和数据规则。

## 复习范围与出题组合

| 选项 | 规则 |
|---|---|
| 章节／页面 | 仅 DOCX（按标题分组）和 PDF（每页一组）提供；默认全选。只发送所选内容，原位置标签不重新编号；所选不足 200 字时不能生成。粘贴文字和只有一个分组的资料不显示该选项 |
| 题型 | 选择题、简答题（学生自评），可多选 |
| 难度 | 基础、标准、拓展，可多选 |

题型和难度全选等同于不限制。提示词要求模型遵守限制，服务端再过滤越界题目；符合条件的题不足时减少题数，不放宽限制凑数。知识点要模型读完材料才存在，所以不能在生成前限定，只能在练习页筛选。草稿记录本次范围和限制。

## 文件输入与原文定位

| 项目 | 规则 |
|---|---|
| 格式 | DOCX、文字版 PDF、粘贴文字 |
| 大小与长度 | 单文件最多 12 MB，PDF 最多 200 页；生成需 200—60000 字符，超限拒绝 |
| Word 位置 | 正文标题与非空段落序号，不推测页码 |
| PDF 位置 | 实际文件页序；跳过无文字页时不重新编号，不一定等于印刷页码 |
| 引用 | 规范化空白、大小写和部分引号后匹配短句，用实际位置替换模型自报位置 |
| 修改预览 | 手动修改文字后改用粘贴段落定位，不继续使用失效的文件位置 |

上传后先检查预览，上传本身不调用模型。导入失败保留上一次成功预览。扫描 PDF 需先做 OCR；Word 图形、公式、批注、页眉页脚不作为已提取知识。表格按文字段落读取，不保留布局；PDF 分栏和公式需对照原件检查。

引用存在只说明相应文字出现在材料中，不能保证答案支持关系、难度或材料本身正确。

## 使用自己的 API

谁生成，谁提供 API；打开已有复习包、作答、自评和查看记录无需 API。

1. 点击“设置自己的 API”，填写服务商给出的接口地址（Base URL）、模型名称和密钥。需兼容 `/chat/completions`，模型能返回合法 JSON；外部地址使用 HTTPS。
2. 在自己的 Windows 电脑上，可勾选“在这台电脑记住 API（加密保存）”；不勾选则仅本次使用。点击“保存设置并使用”不会调用模型；“测试连接并保存设置”发送不含课程资料的短指令，最多等待 25 秒，可能产生少量费用。
3. 检查文字，点击“生成我的复习包”。服务商不支持 JSON 响应参数时，可取消相应勾选后重新启用；关闭该参数仍需返回合法 JSON。

地址可填接口前缀或完整 `/chat/completions` 路径，不能含账号、查询参数或片段。仅本机调试地址允许 HTTP。不保证所有官方服务或中转站兼容。

不勾选“记住”时，密钥只在当前页面内存中保留，经本机服务临时转发，刷新、关闭或跳转到练习页后清除。勾选时使用 Windows DPAPI（当前 Windows 账户的数据保护机制），把加密配置写入当前工作区的 `model-settings.enc.json`；传给加密程序的内容走标准输入，不进入命令行或临时明文文件。网页后续只提交“使用已保存配置”标识，服务端解锁后调用模型，不向网页返回密钥明文。已保存密钥不能通过请求参数被改投到另一个接口地址；修改接口、模型等需重新填写密钥。

两种方式都不把密钥写进课程记录、备份 JSON、应用日志、`localStorage` 或 `sessionStorage`，也不修改 `.env` 或系统设置。失败的连接测试不替换原配置；保存失败会提示，不会静默降级为明文。可点击“忘记这台电脑上保存的 API”，不影响学习记录。共用同一 Windows 账户的人仍可能使用配置；公用电脑不要记住。非 Windows 系统暂只支持本次使用。

点击真实生成后，预览文字和位置标签会发往选择的服务，原文件不发送给模型。使用中转站时密钥和文字会经过站点；费用由密钥账号承担。连接测试不证明出题质量，不必为练习已有包再次填写密钥。

模型生成最长等待 120 秒，可选 1—30 道题。点击后立即弹出进度窗口，显示准备材料、等待模型、核对引用和保存阶段；等待模型时显示移动条与已用时间，不虚构完成百分比。可收起窗口继续浏览，顶部保留任务状态。刷新会接回同一任务，不再次调用模型；重启服务会中断在途任务。资料不足时减少，并分别说明请求数、模型返回数与可练数。草稿记录耗时、模型名及服务返回的数值型 token 用量；当前不估算费用。

认证、额度、接口错误、输出截断和无效 JSON 有对应提示；不向页面返回上游错误原文，不跟随重定向。主机名仅接受本机地址，写请求拒绝来自其他网站的来源。

开发后备：未启用本页 API 时，可读取本机私有 `.env` 中的 `LLM_BASE_URL`、`LLM_MODEL`、`LLM_API_KEY`、`LLM_MOCK` 和可选 `LLM_JSON_MODE`。无需为固定样例创建它，不应提交真实密钥或把该后备用作公开共享额度。

## 数据与代码

| 路径 | 作用 |
|---|---|
| `server.js` | 本机 HTTP 服务和导入、生成、核对、保存包、作答、反馈、错题与练习历史接口 |
| `lib/sources.js`、`lib/verify.js` | 文件提取、位置结构和引用存在性检查 |
| `lib/llm.js`、`lib/prompts.js` | 兼容模型接口与生成提示词 |
| `lib/workflow.js` | 草稿修订、两种开始方式、独立快照、作答、自评、规则报告 |
| `lib/store.js` | 单进程串行更新 JSON，临时写入后重命名；损坏时不静默清空 |
| `lib/model-vault.js` | Windows 账户加密 API 配置，按工作区绑定，网页与学习记录导出不含密钥 |
| `public/` | 导入与可选核对、我的复习包、练习页、错题本、练习历史、API 设置与样式；`filters.js` 为练习筛选逻辑 |
| `test/` | 自动化测试和合成资料 |
| `data/workspaces/<随机标识>/workspace.json` | 当前浏览器对应的本机课程文字、草稿、复习包、作答与反馈；整个 `data` 目录已忽略提交 |

日常无需每次导入：重新打开知速达，用同一浏览器、同一地址继续。关闭服务后需先重新启动。数据分为：

| 内容 | 保存位置 | 关闭后重开 |
|---|---|---|
| 草稿、复习包、已提交成绩、错题依据 | 本机服务的 `data/workspaces/<随机标识>/workspace.json` | 保留；浏览器通过站点 cookie 找到自己的工作区 |
| 尚未提交的答案、当前练习位置 | 当前浏览器的本地存储 | 通常保留；无痕模式、清理站点数据或换浏览器会丢失入口／暂存 |
| 勾选记住的 API | 同一工作区下的 Windows 加密文件 | 保留；同一电脑、Windows 账户及浏览器工作区可使用 |
| 未勾选记住的 API | 当前页面内存 | 刷新或离开后清除 |

“我的复习包”→“换电脑、换浏览器或防丢失？先备份，再恢复”可下载“全部学习记录”JSON，包含当前工作区的课程文字、复习包、已提交记录和本浏览器暂存答案，不含 API 配置／密钥。浏览器存储不可用时仍可备份服务端记录，并提示未包含暂存答案。备份含私人学习资料，请自行保管；最大恢复文件为 20 MB。

恢复合并记录：同 ID 的服务端记录保持已有版本，暂存答案保留时间较新的版本，不改原备份文件。也接受旧版 `data/workspace.json`。清除站点数据后无法自动找回原工作区及加密 API，需用备份恢复记录并重新填写 API；这不等于原电脑文件已被删除。

CSV 导出已保存的题目与核对状态；“仅导出题目 JSON”包含一个包的题目、答案及短引用，不含完整课程或学习记录，不能用于全部记录恢复。

`PORT` 可指定本次端口，`ZHISUDA_DATA_DIR` 可指定私有数据目录，无需修改系统设置。单进程 JSON 不支持多副本共写。旧的 `/api/feedback` 模型汇总接口未接入页面，当前学习记录使用确定的规则。

## 公开部署前

当前只绑定 `127.0.0.1`。不同浏览器通过随机 HttpOnly cookie 使用独立工作区，但没有登录、云同步或身份找回；cookie 隔离不能代替公网权限控制或考试防作弊。不要直接把此本机服务转发到公网。

参见 [部署准备](../ModelScope部署准备.md)：需实现隔离的固定样例，或有权限保护的个人工作区，处理 HTTPS 来源、外部 API 出网限制、费用、资源限制和持久化。尚未创建线上空间或取得线上地址。
