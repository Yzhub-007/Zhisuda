# 知速达 App · 学生自助复习原型

上传课程资料 → 生成复习包 → 直接练习 → 查看原文依据 → 保存学习记录。人工核对可选。

本应用使用 Node.js 原生 HTTP 服务，DOCX／PDF 解析依赖 `fast-xml-parser`、`fflate`、`unpdf`，需要 Node.js 22+，无需前端编译或本地大模型。

## 启动与测试

首次下载，在本目录执行：

```powershell
npm ci --ignore-scripts --omit=optional
npm start
```

打开 [http://127.0.0.1:3000](http://127.0.0.1:3000)。Windows 可双击 `启动知速达.cmd`；脚本只检查运行条件并启动，不自动安装软件或改系统配置。结束时在窗口按 `Ctrl+C`。

点击“载入可演示样例”即可免密钥体验。不要直接双击 HTML 文件，完整功能需要服务运行。

自动测试命令：

```powershell
npm test
```

27 项测试覆盖文件解析、原文定位、API 适配及错误、密钥不持久化、直接练习筛选与计数、可选核对门槛、独立快照、作答自评、导出和重启恢复。测试使用独立临时目录和随机本机端口，不改默认数据；输出默认保留在仓库父级 `_verification`，可由 `ZHISUDA_TEST_ROOT` 指定。

浏览器验证使用本机 Chrome 和外部开发工具，不属于应用运行依赖；模型路径使用模拟服务，尚未证明真实模型质量或学习提升。

## 两种开始方式

| 方式 | 操作与结果 |
|---|---|
| 直接开始练习（默认） | 生成后自动保存练习包并打开练习页；排除引用无法定位、字段不完整或已退回的题目。未经人工核对的题目数量会显示在练习页 |
| 先核对题目，再开始练习 | 生成后进入可选核对页，可修改、通过或退回题目。可随时点击“直接开始练习”，也可处理完全部题目后保存仅含已通过题目的包 |

人工通过要求：题目字段完整、引用存在，并由使用者确认引用能支持答案。编辑后保存会重置该题的人工结论；未保存的修改会阻止开始练习。直接练习不会替使用者勾选人工确认，也不会修改草稿的核对状态。

相同草稿、修订号和开始方式重复保存会返回同一个包；不同方式分别保存。包是独立快照，修改草稿不改变旧包。刷新恢复最近草稿，重启服务保留已保存数据；未保存输入不持久化。

练习时先完成一个难度档位再看答案，选择题由服务端按参考答案核对，简答题由学生对照要点自评。保存自评与卡点后，在“我的复习包”的“查看学习记录”回顾；统计按练习次数，允许同一个人重复贡献，不代表学生人数。

## 文件输入与原文定位

| 项目 | 规则 |
|---|---|
| 格式 | DOCX、文字版 PDF、粘贴文字 |
| 大小与长度 | 单文件最多 12 MB，PDF 最多 200 页；生成需 200—60000 字符，超限拒绝 |
| Word 位置 | 正文标题与非空段落序号，不推测页码 |
| PDF 位置 | 实际文件页序；跳过无文字页时不重新编号，不一定等于印刷页码 |
| 引用 | 规范化空白、大小写和部分引号后匹配短句，用实际位置替换模型自报位置 |
| 修改预览 | 手动修改文字后改用粘贴段落定位，不继续使用失效的文件位置 |

上传后先检查预览，上传本身不调用模型。导入失败保留上一次成功预览。扫描 PDF 需先做 OCR；Word 图形、公式、批注、页眉页脚不作为已提取知识。表格按文字段落读取，不保留布局；PDF 分栏和公式需对照原件检查。

引用存在只说明相应文字出现在材料中，不能保证答案支持关系、难度或材料本身正确。

## 使用自己的 API

谁生成，谁提供 API；打开已有复习包、作答、自评和查看记录无需 API。

1. 点击“设置自己的 API”，填写服务商给出的接口地址（Base URL）、模型名称和密钥。需兼容 `/chat/completions`，模型能返回合法 JSON；外部地址使用 HTTPS。
2. 点击“在本页使用”只启用、不发请求；“测试连接并使用”发送不含课程资料的短指令，最多等待 25 秒，可能产生少量费用。
3. 检查文字，点击“生成我的复习包”。服务商不支持 JSON 响应参数时，可取消相应勾选后重新启用；关闭该参数仍需返回合法 JSON。

地址可填接口前缀或完整 `/chat/completions` 路径，不能含账号、查询参数或片段。仅本机调试地址允许 HTTP。不保证所有官方服务或中转站兼容。

密钥只在当前页面内存中保留，经本机服务临时转发，不写入课程记录、导出、应用日志、`localStorage` 或 `sessionStorage`。刷新、关闭、跳转到练习页或主动清除后需重填；关闭设置弹窗会保留配置。不同页面不共享密钥，修改表单后需重新启用；失败的连接测试不会替换原来启用的配置。

点击真实生成后，预览文字和位置标签会发往选择的服务，原文件不发送给模型。使用中转站时密钥和文字会经过站点；费用由密钥账号承担。连接测试不证明出题质量，不必为练习已有包再次填写密钥。

模型生成最长等待 120 秒，每次最多接受 40 道题。优先生成三个档位各两题，资料不足时减少。草稿记录耗时、模型名及服务返回的数值型 token 用量；当前不估算费用。

认证、额度、接口错误、输出截断和无效 JSON 有对应提示；不向页面返回上游错误原文，不跟随重定向。用户配置不会修改本机文件。

开发后备：未启用本页 API 时，可读取本机私有 `.env` 中的 `LLM_BASE_URL`、`LLM_MODEL`、`LLM_API_KEY`、`LLM_MOCK` 和可选 `LLM_JSON_MODE`。无需为固定样例创建它，不应提交真实密钥或把该后备用作公开共享额度。

## 固定样例与模型输出

| 标识 | 内容 |
|---|---|
| 固定演示样例 | `lib/demo.js` 自编心理学讲义及 6 道预设题，不调用模型；1 道引用不存在，直接练习时排除 |
| 固定模拟结果 | 开发后备启用 `LLM_MOCK=1` 且未启用本页 API 时使用早期 AVL 联调数据，不随材料变化 |
| 模型生成 | 课程文字发送到用户配置的兼容服务，输出保存为草稿；当前只用本机模拟接口验证请求路径 |

标识保留在草稿、复习包和练习页中。固定输出不能作为模型效果证据。

## 数据与代码

| 路径 | 作用 |
|---|---|
| `server.js` | 本机 HTTP 服务和导入、生成、核对、保存包、作答、反馈接口 |
| `lib/sources.js`、`lib/verify.js` | 文件提取、位置结构和引用存在性检查 |
| `lib/llm.js`、`lib/prompts.js` | 兼容模型接口与生成提示词 |
| `lib/workflow.js` | 草稿修订、两种开始方式、独立快照、作答、自评、规则报告 |
| `lib/store.js` | 单进程串行更新 JSON，临时写入后重命名；损坏时不静默清空 |
| `public/` | 导入与可选核对、我的复习包、练习页、API 设置与样式 |
| `test/` | 自动化测试和合成资料 |
| `data/workspace.json` | 本机课程文字、草稿、复习包、作答与反馈，首次操作后创建，已忽略提交 |

CSV 导出已保存的题目与核对状态，JSON 导出一个包的题目、答案及短引用，不包含完整课程或练习记录；当前没有 JSON 导入。完整备份需停止服务后私下复制 `data` 文件夹。

`PORT` 可指定本次端口，`ZHISUDA_DATA_DIR` 可指定私有数据目录，无需修改系统设置。单进程 JSON 不支持多副本共写。旧的 `/api/feedback` 模型汇总接口未接入页面，当前学习记录使用确定的规则。

## 公开部署前

当前只绑定 `127.0.0.1`，没有登录与用户资料隔离。练习前不下发答案是交互设计，不能代替权限控制或考试防作弊。不要直接把此本机服务转发到公网。

参见 [部署准备](../ModelScope部署准备.md)：需实现隔离的固定样例，或有权限保护的个人工作区，处理 HTTPS 来源、外部 API 出网限制、费用、资源限制和持久化。尚未创建线上空间或取得线上地址。
