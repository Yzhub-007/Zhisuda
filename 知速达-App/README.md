# 知速达 App(初版框架)

基于课程资料溯源的 AI 智能复习包生成工具。零依赖,需要 Node.js 22+。

## 运行

```bash
cp .env.example .env     # 填写 LLM_API_KEY,或把 LLM_MOCK 设为 1 先看界面
npm start                # 打开 http://127.0.0.1:3000
npm test                 # 核对逻辑的单元测试
```

## 结构

| 文件 | 作用 |
|---|---|
| `server.js` | 静态页面 + `/api/generate`、`/api/feedback` |
| `lib/llm.js` | 对接任意兼容 OpenAI 接口的模型(DeepSeek、通义千问、Kimi 等) |
| `lib/prompts.js` | 生成与反馈汇总提示词(JSON 输出) |
| `lib/verify.js` | **依据核对**:模型给的原文短句必须真的出现在讲义里,否则降级为"需人工核验" |
| `public/` | 教师工作台:生成、逐题审核、导出、反馈汇总 |

## 边界

- 只监听 127.0.0.1,**没有登录认证**,不要暴露到公网。
- `.env` 里有密钥,不要提交或分享。
- 系统核对的是"引用是否存在于讲义",**不是**"引用能否支持答案"。后者必须由教师判断,不要把引用存在率当作依据准确率写进材料。
- 讲义只支持粘贴文字,不解析 PDF。
- 没有数据库,审核结果刷新页面即丢失,请先导出 CSV。
- 学生端目前仍是 `知速达-MVP/student.html`,尚未接入本服务。
