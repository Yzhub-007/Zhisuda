自动保存，随时回来

平时直接打开就能继续，无需每次导入。

复习包、已提交成绩和错题保存在这台电脑；没做完的答案自动暂存在当前浏览器。关闭网页后，用同一浏览器、同一地址打开知速达，再点对应复习包即可继续。

关掉知速达服务后需先重新启动。请勿清除站点数据或使用无痕模式；当前没有账号和云同步，换浏览器不会自动找回原工作区。记录不会自动上传 GitHub。

换电脑、换浏览器或防丢失？先备份，再恢复

① 点击“备份全部学习记录”，把下载的 JSON 文件放到自己找得到的位置。② 换环境后在这里选择该文件恢复。平时使用不需要这两步。

包含课程文字、复习包、已提交成绩、错题依据和本浏览器暂存的答案；不包含 API 密钥。文件含私人学习资料，请自行保管。

也支持旧版 data 文件夹中的 workspace.json。恢复会合并记录，保留已有内容；“仅导出题目”的 JSON 不能用于恢复。

      你的模型，你来选择

      模型设置

      支持兼容对话接口的官方服务和中转站。费用由你填写的账号承担，知速达不收取模型调用费。

      填写服务商给出的兼容地址；也支持以 /chat/completions 结尾的完整地址。外部服务需使用 HTTPS。

      保存方式由你选择

      勾选“记住”后，用当前 Windows 账户加密保存在本机，页面不会取回密钥明文。不勾选则仅本次使用，刷新或离开后清除。密钥不进入课程记录、备份 JSON 或应用日志；共用同一 Windows 账户的人仍可能使用该配置。

      使用中转站时，密钥和生成文字会经过该站点，请选择可信服务。在公用电脑上请勿勾选“记住”。

      “保存设置并使用”不会调用模型，不消耗模型额度。连接测试会向服务商发送一条简短指令，不含课程资料，可能产生少量模型费用；最多等待 25 秒。清除浏览器站点数据后，本机加密设置也不会自动找回，需重新填写。
