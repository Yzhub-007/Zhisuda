## 队长交接

1. 拉取 GitHub 最新 `main`，按[魔搭手册](../魔搭部署检查与操作手册.md)完成 Docker 适配和预览验证。当前代码仍只支持本机监听，不能直接原样公开部署；重点处理监听地址、7860 端口、HTTPS 来源校验和持久化。
2. 部署时先用固定自编样例；检查资源限制、用户 API 出网限制和工作区管理。不要给所有访客配置个人共享密钥，不上传真实笔记或本地 `data`。
3. 获得魔搭 HTTPS 体验链接后，用无痕窗口确认评委无需加入团队即可打开，再把实际链接补入仓库首页。仓库地址为 https://github.com/Yzhub-007/Zhisuda 。
4. 提交页面填写正式项目名称“知速达——基于课程资料溯源的 AI 智能复习包生成工具”、GitHub 链接和魔搭链接，上传本目录的商业 PDF、Demo MP4。2026-10-20 核对网页上传规则：商业材料接受 PDF/PPT/PPTX，最大 30 MB；Demo 接受 MP4/WebM/MOV，最大 200 MB。Demo PDF 仅供备用阅读，不能替代视频栏上传。最终以实际表单提示为准。
5. 完成“正式提交”并保存成功状态截图。选手手册标注截止为 **2026-10-20 23:00**，以赛题页及赛事群最新通知为准；只保存草稿不会进入评审。
