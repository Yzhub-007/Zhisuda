# 知速达 Demo 讲稿与说明

## 文件使用

- `知速达-Demo演示.mp4`：约 100 秒，字幕版，无旁白；由实际本地界面的连续步骤截图编排，不是实时模型生成录像。
- `知速达-Demo演示.pdf`：与视频对应的界面说明，便于静音阅读和备用展示。
- `知速达-商业一页纸.pdf`：单页项目价值与落地说明；可编辑文字见 `商业一页纸.md`。

演示使用仓库 `lib/demo.js` 内的自编《记忆与学习策略》，不含真实学生笔记、身份资料或 API 密钥。全部作答为演示操作。固定样例有 6 道预设草稿题，其中 1 道故意设置不存在的引用，直接练习时排除后为 5 道；题量与题型设置只作用于实时生成，不改变固定样例。

## 约 100 秒讲稿

**开场（0—8 秒）**

知速达帮助学生把自己的课程资料变成可核对、可继续练习的复习包。这里展示实际本地界面，使用固定自编样例，不调用模型。

**导入与设置（8—23 秒）**

上传 DOCX 格式的 Word 文件、文字版 PDF，或直接粘贴文字。实时生成可以选择 1—30 题、仅选择题或仅简答题，以及难度和复习范围。使用自己的资料生成时，用户提供兼容的 API；人工核对可选。

**开始练习（23—33 秒）**

点击载入固定样例即可免密钥体验。样例预设 6 道草稿，系统排除 1 道引用不存在的题目，实际可练 5 道。页面分别显示数量与固定样例标识。

**作答和原文依据（33—49 秒）**

先独立作答，再查看反馈。答错的选择题标红，展开后能看到课程名称、原文位置和引用短句。找到引用只是方便核对，仍要判断它能否支持答案。

**暂停与继续（49—60 秒）**

练习可以暂时退出。返回首页后，复习包显示已答数量；用同一浏览器、同一地址重新打开即可继续，平时不需要反复导入 JSON。

**简答自评（60—72 秒）**

简答题不假装自动评分。对照参考要点，自己选择掌握、部分掌握或未掌握，完成本轮后保存学习记录。

**错题本（72—85 秒）**

客观错题和自评未掌握的简答题进入错题本，可按课程、知识点和时间筛选，并单题或整组重练。

**历史与收束（85—100 秒）**

练习历史按次保留，可回看当次回答。当前是学生自助复习原型；作者已做初步试用，下一步进行小范围学生验证与云端部署适配。我们要验证的是，从整理资料到真正开始练习，能否更省事、更容易核对。

## 现场备用操作

1. 在项目应用目录启动本地服务，打开首页；不要双击 HTML。
2. 点“载入可演示样例”；确认显示 5 道可练题和固定样例提示。
3. 第一题故意选 A，点“提交这道题，查看反馈”，展开课程原文依据。
4. 点“保存并返回首页”，从复习包继续，确认回答和反馈保留。
5. 完成其余题目，对简答题进行自评，再点“完成本轮”。
6. 打开错题本展示筛选与单题重练，再打开练习历史。

已有复习包作答无需 API。要演示实时生成，必须使用有授权的资料及自己提供的 API，并确认费用；本视频没有替代这项质量验证。

## 可能被问到

**和通用 AI 出题有何区别？** 把本课程引用定位、作答、暂停续练和错题回练接在一起，价值需通过真实任务比较验证。

**是否保证答案正确？** 不保证。检查引用是否存在并显示位置，不能替代对答案支持关系和笔记准确性的判断。

**资料和密钥存在哪里？** 当前课程记录保存在运行服务的电脑，未提交答案暂存在浏览器；生成文字会发往用户设置的模型服务。可选记住 API 仅在 Windows 账户加密下支持。没有账号或跨设备云同步，公网部署仍需适配。

**有没有提分数据和收费？** 尚无；目前是免费原型，作者初步试用不等于学习效果研究。先做小范围验证，再决定商业方案。
